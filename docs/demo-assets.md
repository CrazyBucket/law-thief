# Demo visual assets

## Mini Magick Shoots 2

- Source: [Mini Magick Shoots 2](https://xyezawr.itch.io/free-pixel-effects-pack-10-mini-magick-shoots2) by XYEZAWr.
- Local install path: `assets/demo/mini-magick-shoots-2/`.
- The projectile renderer uses the red/orange, green, purple, blue, and gold variants for fire, poison, arc, ice, and explosion gem shots respectively.
- The source page permits use and modification in free and commercial games, with optional credit, but prohibits redistribution or resale. The raw PNG frames are consequently ignored and must be obtained from the source page by each checkout that needs them.

When that local directory is absent, gem shots automatically use the standard Wind projectile frames. Gameplay is unaffected.

## Foozle Pixel Magic Effects

The CC0 Foozle Pixel Magic Effects frames used by the ordinary projectile and hit feedback are committed in `assets/vfx/foozle-pixel-magic-effects/`; see `LICENSE.txt` in that directory.
